# 硅链 / 锂链专题方法论

> Frank 期货主战场的两条核心链——硅链（工业硅 SI / 多晶硅 PS，广期所）+ 锂链（碳酸锂 LC，广期所）。

## 主战场定位

| 链 | 主力合约 | 核心叙事 | 关键数据 |
|---|---|---|---|
| **硅链** | SI2611 / PS2611 | **反内卷弱现实**（政策预期 vs 现货疲软） | 老仓单注销 / 停炉节奏 / 现货基差 |
| **锂链** | LC2701 | **强现实 vs 弱预期博弈窗口** | SMM 周度库存 / 盐湖检修 / 津巴布韦到港 |

两条链都做 **L1 分析层 → L2 咨询层 → L3 行动层** 三层升级。

## 硅链（工业硅 SI + 多晶硅 PS）

### 核心叙事：反内卷弱现实

- **政策预期**（L1）：反内卷 + 老仓单注销 + 停炉节奏 → 远月升水
- **弱现实**（L1）：现货需求疲软 + 利润亏损 + 期现套利窗口收窄
- **扳机事件**（L1）：新疆电价改革 / 老仓单集中注销（11 月底）

### 现货价表规范（Frank 沉淀，缺一不算客户可执行）

#### 多晶硅厂利润行（必含）

口径：1.6 元/kg 单公斤亏损（Mysteel 8/21 周报口径），佐证"挺价没量"。

### 市场分割逻辑（重要判据）

期货盘 SI 价格的逻辑（反内卷预期 + 停炉 + 老仓单注销）基本只传导到**标准品期现市场**；**非标品现货端**（占工业硅月流通 ~30-40%）的价格取决于当地铝厂/铸造厂/磨粉厂的开工率，与期货盘脱钩。

**实务判断**：当听到"工业硅现货跟涨 5%"时，必须问**哪个标的**——通氧 553# 跟涨 ≠ 99 硅跟涨，后者可能纹丝不动。

### 客户角色与套保方向

| 角色 | 价值链方向 | 套保方向 | 关键约束 |
|---|---|---|---|
| **上游冶炼厂** | 怕跌 | **卖出套保** | 30%→反弹加至 50%+→回落释放至 20%+惜售 |
| **中游贸易商** | 怕基差回归 | **反套（卖现买期）** | 卖现货端必须真实销售渠道（不通氧 553#/441#），不能依赖交割库一刀切 |
| **下游拉晶厂** | 怕涨 | **买入套保** | 分批建仓，远期原料 30%-50% |

### 验证信号四档价差触发器

SI2611-SI2612 价差：

- **收窄至 -300 元**（远月升水收窄）：多头止盈信号
- **平衡 -300~-500 元**：震荡
- **走扩 -500~-700 元**：空头加仓信号
- **突破 -700 元**：政策预期强烈，逼仓窗口

⚠ **切忌**：用反向数值判断——基差和价差口径必须统一"近月−远月"。

## 锂链（碳酸锂 LC）

### 核心叙事：强现实 vs 弱预期博弈窗口

- **强现实**（L1）：SMM 大样本库存连续 8 周去库至 86,392 吨（年内最低）+ 8 月电池排产 311.85 GWh（+5.71%, 储能首次反超动力）+ 盐湖检修（周产盐湖端 -985 吨）
- **弱预期**（L1）：津巴布韦锂矿陆续到港 + 江西枧下窝 9 月中批复窗口 + 远月 LC2707 已跌至 149,560
- **扳机事件**（L1）：8/26 宜春生态局撤销枧下窝原环评报告 → 9/5-9/10 观察批复 → 决定强现实还是弱预期占优

### 现货价表 7 行（必含）

| 行 | 标的内容 |
|---|---|
| 1 | 电池级碳酸锂主流价 |
| 2 | 新料客供 |
| 3 | 工业级碳酸锂 |
| 4 | 准电碳 |
| 5 | 氢氧化锂 |
| 6 | 锂精矿 6% CIF |
| 7 | 利润行（+0.3 万/吨 微利） |

### 客户角色与套保方向（与硅链相反）

| 角色 | 价值链方向 | 套保方向 | 关键约束 |
|---|---|---|---|
| **上游锂盐厂** | 怕跌 | **卖出套保** | 30%→反弹 16 万+ 加至 50%+→回落 14 万以下释放至 20%+惜售 |
| **中游贸易商** | 怕基差回归 | **短期不推荐反套**（基差为负）；月差套利 LC2701-LC2705（当前 +2380）→ 走扩 +3500 可做"买近卖远"，持有 30-45 天别死守 | 基差 -1,050 时反套不可做（期货升水） |
| **下游正极厂** | 怕涨 | **买入套保** | 分批买入套保 30%-50% 远期原料；超跌 14 万以下加至 70%+；跳涨 16.5 万不追涨 |

### 验证信号四档价差触发器

LC2701-LC2705 价差：

- **收窄 +1500**：多头止盈
- **平衡 +2000~+3500**：震荡
- **走扩 +4000**：空头加仓
- **突破 +5000**：逼仓窗口

### 关键提示五条（博弈窗口的市场分割）

1. 电池级是交割基准品
2. 工业级/准电碳是主流走量品
3. 中小正极厂混包准电碳
4. 储能反超动力旺季 vs 远期宽松
5. "舒适区" 14-15 万（跌破 14 万才会大面积减产）

## 跨链对冲参考

硅链 vs 锂链的相关性研究（Frank 实战沉淀）：

- **同向**：当广期所整体反内卷叙事升温时，两链远月升水同步走扩
- **反向**：当电池排产强势（锂链强现实）+ 多晶硅亏损（硅链弱现实）时，两链出现劈叉
- **对冲比例**：1:1.5（硅链 : 锂链，按合约乘数调整），持有周期 60-90 天
