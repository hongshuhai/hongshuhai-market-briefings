# 七步市场温度扫描框架

> Frank 日常宏观对冲指标的核心方法论——双场景共用，美股映射到 1-6 步，商品映射到 2-4 步。

## 框架起源

七步法源自 2024 年开始做期货经纪后，每天早盘前必须回答的一个问题：

> **"今天市场处于什么状态？我的客户该买入、卖出、还是观望？"**

传统的"看盘 + 感觉"无法回答这个问题——它需要**结构化、可量化、可复盘**的温度计。七步法就是这套温度计。

## 七步定义

### 第 1 步：利率曲线（仅美股）

| 指标 | 数据源 | 含义 |
|---|---|---|
| 2Y 收益率 | FRED / WebSearch | 联储短期预期 |
| 10Y 收益率 | FRED / WebSearch | 中期增长 + 通胀预期 |
| 30Y 收益率 | FRED / WebSearch | 长期增长 + 财政赤字 |
| 2s10s 利差 | 公式 | 衰退信号（负值 = 倒挂） |
| 2s30s 利差 | 公式 | 长端衰退信号 |

**温度读数规则**：
- 倒挂走阔（2s10s < -50bp）：🧊 衰退担忧升温
- 陡峭化（2s10s > +50bp）：🔥 再通胀预期
- 区间震荡（-50bp ~ +50bp）：中性

### 第 2 步：指数结构

#### 美股

| 指标 | 含义 |
|---|---|
| SPX 收盘 | 大盘风险偏好 |
| DJI 收盘 | 价值股 / 老经济 |
| IXIC 收盘 | 成长股 / 科技 |
| RTY 收盘 | 小盘 / 国内经济 |

**领涨板块文字**：从 WebSearch 抓 SPX 11 个板块的当日涨跌，列涨幅 Top 3 + 跌幅 Top 3。

#### 商品（板块轮动 16 品种）

按 20 日涨跌幅排序：

| 板块 | 主力合约 |
|---|---|
| 黑色 | RB / I / J / JM |
| 能化 | SC / FU / BU / TA / MA / EG / PF |
| 农产品 | M / Y / P / OI / SR / CF |
| 贵金属 | AU / AG |

### 第 3 步：原油链

| 美股 | 商品 |
|---|---|
| WTI（CL） | SC（上海原油） |
| Brent | FU（燃油）/ BU（沥青） |

**温度读数规则**：
- +3% 以上：⚡ 供给冲击（地缘/OPEC）
- -3% 以下：⚡ 需求担忧
- 区间震荡：中性

### 第 4 步：贵金属 + 工业金属

| 美股 | 商品 |
|---|---|
| COMEX 黄金（GC） | 沪金（AU） |
| COMEX 白银（SI） | 沪银（AG） |
| LME 铜（HG） | 沪铜（CU） |

**金铜比**（黄金 ÷ 铜）：衰退信号
- > 250：衰退担忧（避险买金 + 工业金属跌）
- < 180：通胀预期（铜强金弱）

### 第 5 步：波动率（仅美股）

| 指标 | 含义 |
|---|---|
| VIX（30 日） | 标普期权隐含波动率 |
| VIX9D（9 日） | **前端恐慌指标**——盘前重点关注 |
| VVIX | VIX 的波动率（VIX of VIX） |
| 期限结构（VIX 主连 vs VIX 远月） | contango = 平静预期；backwardation = 短期恐慌 |

**3 触发器之一**：VIX9D 走扩 = 前端恐慌信号，触发 risk-off 警示。

### 第 6 步：信用（仅美股）

| 指标 | 含义 |
|---|---|
| JNK（高收益债 ETF） | 信用利差代理 |
| HYG（同上，更广） | 信用利差代理 |
| TLT（20Y+ 国债 ETF） | 久期代理 |

**JNK/HYG vs TLT 比值**：信用 vs 久期
- 比值上行 = risk-on（信用扩张）
- 比值下行 = risk-off（避险买长债）

### 第 7 步：日历与事件

| 美股 | 商品 |
|---|---|
| 财报映射（Magnificent 7 季报日历） | 持仓数据（CFTC 周度） |
| 宏观数据（CPI/PCE/非农/ISM/PPI） | 基差（现期价差） |
| 联储讲话（官员点阵图） | 价差窗口（跨期/跨品种） |

## 温度判定逻辑

七步读完，给出**主观综合温度**：

| 温度区间 | 含义 | 行动建议 |
|---|---|---|
| 🔥 偏热（≥ 35°C） | risk-on + 通胀预期 | 顺势做多，但要警惕反转 |
| 中性（25-35°C） | 多空平衡 | 区间策略，快进快出 |
| 🧊 偏冷（≤ 25°C） | risk-off + 衰退担忧 | 防御为主，等待催化 |

**重要约束**：温度是**主观读数**，**无固定权重公式**，**六板块不横向可比**——读者看到"27-33°C 正常区间"之类伪量化刻度时要警惕。

## 商品的七步映射

商品报告的七步略有不同——第 1 步（利率）映射为**宏观大气候**，第 5/6 步（波动率/信用）映射为**基差/价差窗口**：

```
1. 利率 → 宏观大气候（美元/PPI/PMI/M2）
2. 指数 → 板块轮动 16 品种
3. 原油链 → SC/FU/BU
4. 贵金属 → AU/AG/CU
5. 波动率 → 价差窗口（跨期/跨品种）
6. 信用 → 基差（现期价差）
7. 日历 → 持仓 + 事件
```

详见 [commodity/scripts/commodity_morning_report.py](../commodity/scripts/commodity_morning_report.py) 的 `CONTEXT["temps"]` 字段。
