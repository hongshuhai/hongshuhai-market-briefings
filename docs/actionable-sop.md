# 客户级 Actionable 精细化 SOP

> Frank 报告不是给自己看的，而是给**客户群**用的——这是研究报告与产品报告的根本区别。本 SOP 是把"分析师建议"升级到"客户可执行"的三层金字塔。

## 三层金字塔（核心方法论）

```
                  ┌──────────────────────────┐
                  │   L3 行动层（绿盒）       │  ← 谁、做什么、何时、量化参数
                  └──────────────────────────┘
                ┌──────────────────────────────┐
                │   L2 咨询层（黄盒）          │  ← 关键问题拆解、口径备注
                └──────────────────────────────┘
              ┌──────────────────────────────────┐
              │   L1 分析层（蓝盒）              │  ← 说了什么 + 为什么
              └──────────────────────────────────┘
```

### L1 分析层：说了什么 + 为什么

- 数据点（如"价差走扩 355 元"）
- 逻辑链（如"反内卷预期升温 → 老仓单注销 → 远月升水"）
- 不确定性（如"9 月批复窗口待观察"）

### L2 咨询层：可脱口回答的关键问题

- "为什么弱？"的三句话拆解
- "利润分化"的口径备注
- "市场分割"的关键判据

### L3 行动层：分角色客户的具体动作

- **上游冶炼厂** → 卖出套保（30% → 反弹加至 50%+ → 回落释放）
- **中游贸易商** → 反套（卖现买期）+ 真实销售渠道约束
- **下游拉晶厂** → 买入套保（分批建仓 30%-50%）

## Actionable 五条铁律（缺一不算客户可执行）

### 铁律 1：头寸变动要可执行

❌ **错**：`建议加套保至 50%+`
✅ **对**：`释放卖套保头寸 50% → 30%`，附现货端动作（惜售/出货），附复建条件（反弹到哪个区间再分批重建）

### 铁律 2：场景拆开

❌ **错**：`价格上下变动时调整套保头寸`
✅ **对**：拆成两条：
- 场景 A（价格向下）：释放头寸至 20%，惜售现货
- 场景 B（价格向上）：加仓至 50%，出货节奏放缓

### 铁律 3：时间周期要标注

❌ **错**：`净利测算约 100 元/吨`
✅ **对**：`净利测算约 100 元/吨（持有周期 60-90 天；如提前收敛到 -200 元以内，见好就收）`

### 铁律 4：验证信号给边界值

❌ **错**：`价差收敛时止盈，价差走扩时加仓`
✅ **对**：
- 收窄至 **-300 元**（远月升水收窄）：多头止盈信号
- 平衡 **-300 ~ -500 元**：震荡区间
- 走扩 **-500 ~ -700 元**：空头加仓信号
- 突破 **-700 元**：逼仓窗口

### 铁律 5：加 ⚠ 警示框

每个 Actionable 末尾必须加：

```
⚠ 切忌：
- 不要在远月升水 > 700 元时仍持有空头（逼仓风险）
- 不要在反弹 > 9500 元时追涨（已超买区间）
- 反套净利 < 100 元/吨时不要死守（机会成本覆盖不了）
```

## 套保方向的价值链判断

| 角色 | 价值链方向 | 怕什么 | 套保方向 | 工具 |
|---|---|---|---|---|
| 上游冶炼厂/锂盐厂 | 生产者 | 价格下跌 | **卖出套保** | 期货空头 |
| 中游贸易商 | 中间商 | 基差回归 | **反套（卖现买期）** | 卖现货 + 买期货 |
| 下游加工/拉晶/正极厂 | 消费者 | 价格上涨 | **买入套保** | 期货多头 |

**关键约束**：中游贸易商的"卖现货"端必须真实销售渠道，不能依赖交割库一刀切——这是市场分割的具体落地。

## 净利测算口径（反套）

```
净利 = 基差 − (仓储费 + 资金成本)
      = 基差 − (0.05 元/吨/天 × 持仓天数 + 期货保证金 × 年化利率)
```

**6 个月内回归约 300 元/吨**；超出 250 元/吨的净利才能覆盖机会成本。

## 跨链比较（重要判据）

禁止直接用基差绝对值跨品种比较——必须用**基差率**：

```
基差率 = 基差绝对值 ÷ 标的价
```

| 链 | 9/2 基差 | 标的价 | 基差率 | 反套净利 |
|---|---|---|---|---|
| 硅链（SI） | +410 | 8,790 | 4.7% | ~100 元/吨 ✅ |
| 锂链（LC） | +640 | 153,000 | 0.4% | 远低于持有成本 ❌ |

## 追保压力表（紧急动作触发）

当客户持仓接近追保线时，必须主动通知：

| 价格逆向幅度 | 初始保证金占用 | 维持保证金状态 | 建议动作 |
|---|---|---|---|
| +5% | 50% | 安全 | 持有 |
| +10% | 100% | **触及追保** | 减仓 30% |
| +15% | 115%（超限） | **强平风险** | 立即减仓 50%+ 追加保证金 |

公式（以硅 SI2611 卖保 30% = 600 手为例）：

```
初始保证金 = 价格 × 手数 × 乘数 × 保证金率
            = 8,790 × 600 × 5 × 10% = 263.7 万
维持保证金 = 初始 × 80% = 210.96 万
追保 = 浮亏 − 20% × 初始
```
